Inside the browser

Page thread

Launcher + renderer

Owns the canvas. Replays recorded draw commands with WebGPU, handles keyboard, mouse and gamepad.

Game thread (worker)

The recompiled game

Runs the translated code. D3D9 calls are recorded as commands; vertex shaders run on the CPU, four vertices at a time.

Audio

Software mixer

Re-implements DirectSound: 3D positioning, limiter, fades. A shared ring buffer feeds the audio clock.

Files

Streamed on demand

Big archives become sparse files in OPFS; 1 MB chunks are fetched by range request the first time the game reads them. About 100 MB to reach level 1, not 1.5 GB.

Hard problems solved along the way

• A lost wake-up in the game's I/O thread pool froze level loading (a sleep-poll wait hid it).
• Black sky and sea: Direct3D and WebGPU cull modes map straight through, swapping them removed the sky.
• Crackling audio, traced from the speaker back to one wrong cast: a signed 32-bit read became unsigned, so MMX mixing clipped.
• 1080p: the game's 800×600 default patched in the generated code; 16:9 letterboxing in the renderer.
